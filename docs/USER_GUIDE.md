# BERTI 재고관리 사용자 매뉴얼

## 1. 시작하기

### 1.1 첫 접속 (스마트폰 권장)
1. 관리자가 제공한 URL을 모바일 Chrome/Safari에서 엽니다.
2. 화면 하단의 **공유 → 홈 화면에 추가**를 눌러 앱처럼 설치하세요.
   - iOS: Safari에서만 가능합니다.
   - Android: Chrome에서 자동 설치 배너가 표시됩니다.
3. 홈 화면의 아이콘으로 실행하면 전체화면 모드로 동작합니다.

### 1.2 회원가입 → 로그인
1. **회원가입** 화면에서 이메일·비밀번호·이름·소속·연락처를 입력합니다.
2. 메일함에서 인증 메일을 확인합니다.
3. 관리자 승인이 활성화된 경우 **승인 대기** 화면이 표시됩니다. 관리자가 승인하면 새로고침으로 진입할 수 있습니다.

### 1.3 매직 링크 로그인
비밀번호가 기억나지 않으면 로그인 화면의 **매직링크로 로그인**을 사용하세요. 입력한 이메일로 1회용 링크가 전송됩니다.

---

## 2. 입출고 등록 (현장)

### 2.1 입고
1. 하단 탭에서 **입고**를 선택합니다.
2. 위치는 마지막 사용 값이 자동 선택됩니다(변경 가능).
3. **QR 스캔 버튼**(우측)을 눌러 자재 QR/바코드를 비추거나, **자재 선택**으로 검색합니다.
4. 수량을 입력하고(숫자 키패드가 자동 표시), 필요하면 거래처/비고/사진을 추가합니다.
5. 하단 **입고 저장** 버튼을 누릅니다.

### 2.2 출고
입고와 동일한 절차이며, 사용처/현장명을 입력합니다. **현재 재고를 초과하는 수량은 저장되지 않습니다.**

### 2.3 창고 간 이동
"더보기 → 창고 간 이동"에서 출발지·도착지·자재·수량을 입력하면 한 번에 두 위치의 재고가 동시에 갱신됩니다.

### 2.4 사진 첨부
- 카메라 아이콘을 눌러 즉시 촬영하거나 갤러리에서 선택할 수 있습니다.
- 여러 장 첨부 가능합니다. 업로드 후 우상단 X로 제거할 수 있습니다.

### 2.5 오프라인 사용
- 통신이 끊긴 상태에서도 입출고를 등록할 수 있습니다. 화면 상단에 **오프라인 모드** 배너가 표시되며, 입력은 단말기에 임시 저장됩니다.
- 다시 온라인이 되면 자동으로 서버와 동기화되며, 동기화 결과가 토스트로 안내됩니다.
- "더보기 → 설정"에서 큐 상태와 수동 동기화가 가능합니다.

## 3. 조회

### 3.1 대시보드
- 상단에 위치별 재고 합계 카드가 가로로 펼쳐집니다.
- 그 아래에 최근 입출고 10건이 표시됩니다.

### 3.2 재고 현황
- "더보기 → 재고 현황"에서 위치 필터와 검색을 사용할 수 있습니다.
- **빨간색**으로 표시된 행은 안전재고 미달입니다.

### 3.3 입출고 이력
- 기간/위치/구분 필터로 조회하며, **CSV 다운로드**(Excel 한글 호환)가 가능합니다.

---

## 4. 관리자 기능

### 4.1 자재 관리
- 자재 코드는 고유해야 합니다.
- 안전재고 값을 설정하면 재고 현황에서 미달 자재가 자동으로 표시됩니다.

### 4.2 위치(창고) 관리
- 창고/현장 구분이 가능하며, 주소·비고를 함께 관리합니다.
- 재고가 있는 위치는 삭제되지 않습니다.

### 4.3 사용자 관리
- 가입자 목록 확인, 관리자 권한 부여/회수, 가입 승인/취소.
- 본인 권한 강등은 차단됩니다.

### 4.4 Excel 일괄 Import
1. "더보기 → Excel 일괄 Import"에 진입합니다.
2. 탭을 선택합니다.
   - **자재 마스터**: 자재 코드 기준 upsert
   - **초기 재고**: 위치명 + 자재코드 + 수량 (덮어쓰기)
3. 파일 선택 후 검증 미리보기가 표시되며, **유효 행 일괄 등록** 버튼으로 적용합니다.

지원되는 헤더(한글/영문 자동 인식):
- 자재 마스터: `자재코드/코드/code`, `자재명/품목명/name`, `규격/spec`, `수종/species`, `색상/패턴/color`, `단위/unit`, `박스당수량/qty_per_box`, `박스당면적/area_per_box`, `안전재고/safety_stock`, `비고/memo`
- 초기 재고: `위치/창고/현장/location`, `자재코드/코드/code`, `수량/재고/quantity`

### 4.5 보고서 / Excel 내보내기
- 재고 스냅샷: `yymmdd_BERTI_재고리스트.xlsx`
- 기간별 입출고: `yymmdd_BERTI_입출고이력.xlsx`

### 4.6 감사 로그
- 입출고 수정/삭제 이력의 before/after를 확인합니다.

## 5. 자주 묻는 질문

**Q. QR 스캔이 안 됩니다.**
- iOS Safari 등 일부 브라우저는 BarcodeDetector를 지원하지 않습니다. 이 경우 스캔 화면 하단에 직접 코드를 입력해 주세요(수동 입력 가능).

**Q. 출고 시 "재고 부족" 오류가 납니다.**
- 해당 위치의 현재고가 입력한 수량보다 적습니다. 재고 현황에서 실제 수량을 확인하세요.

**Q. 오프라인에서 입력했는데 안 보입니다.**
- 큐에 임시 저장된 상태입니다. 온라인이 되면 자동 동기화됩니다. "더보기 → 설정"에서 미동기 건수를 확인할 수 있습니다.

**Q. 비밀번호 재설정**
- 로그인 화면에서 매직링크로 로그인 후, 추후 비밀번호 변경 기능을 사용해 주세요(차후 업데이트).
